# Senior Engineering Leadership Portfolio

## Outcome
Rebuild the existing portfolio as a polished, recruiter-focused single-page experience while preserving Shruthi Sridhara’s career story, achievements, metrics, projects, principles, learning journey, and contact details.

## Build
- Create a sticky, accessible navigation with active-section highlighting, smooth scrolling, a compact mobile menu, and back-to-top control.
- Build an executive hero with the original positioning statement, role/location status, contact actions, an understated initials portrait treatment, and four measurable outcomes.
- Present the six operating principles as a structured leadership grid.
- Reframe the three programmes as an elegant career timeline with clear challenge, approach, outcome, context, and dates.
- Group the existing skills into focused categories without changing or omitting the named technologies.
- Preserve the five leadership beliefs and both current learning initiatives in scannable editorial layouts.
- Recreate the peer-feedback theme as a refined leadership-qualities visualization.
- Add a concise contact section and footer with the existing LinkedIn, email, location, and availability details.

## Design system
- Use a restrained white, mist-gray, charcoal, and slate-blue palette with IBM Plex Sans.
- Use generous spacing, quiet 6–8px corners, thin rules, soft elevation, and disciplined typography.
- Keep motion subtle and accessible, with scroll reveals disabled for reduced-motion preferences.
- Keep all color, type, spacing, shadow, and motion values centralized in the project’s design system.

## Technical details
- Implement reusable React/TypeScript sections and small UI components.
- Keep the site as one intentionally scrolling portfolio page because the requested navigation is section-based.
- Add section-aware navigation via IntersectionObserver and keyboard-safe controls.
- Add complete page metadata, semantic structure, accessible labels, and responsive behavior.
- Add a professional SVG favicon, a bundled social-preview image, and update the README with run/build instructions.
- Verify the rendered page at desktop and mobile widths, including navigation and console state.
